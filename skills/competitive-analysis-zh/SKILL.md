# 竞品分析 (competitive-analysis-zh)

## When to Use

- "帮我分析一下竞品"、"做个竞品对比"
- "我们和 [产品名] 比有什么优劣势"
- 立项前需要市场调研
- `/competitive-analysis-zh [你的产品] vs [竞品1, 竞品2]`

## Quick Reference

```
/competitive-analysis-zh [产品描述或名称]

可选参数：
  --focus=功能      # 重点对比功能矩阵（默认）
  --focus=商业      # 重点对比商业模式 / 定价
  --focus=用户      # 重点对比用户定位 / 体验
```

## Procedure

1. **确认分析范围**
   - 你的产品定位 / 核心功能是什么？
   - 主要竞品是哪几个（直接竞品 + 间接竞品）？
   - 分析目的：立项决策 / 功能规划 / 融资材料？

2. **输出竞品分析报告**

```markdown
## 一、市场概况
- 赛道定义：[这个市场解决什么问题]
- 市场规模：[已知数据，无则标注"待调研"]
- 竞争格局：[第一梯队 / 细分玩家]

## 二、竞品概览
| 产品 | 核心定位 | 目标用户 | 商业模式 | 融资情况 |
|------|----------|----------|----------|----------|
| [我方] | | | | |
| [竞品A] | | | | |
| [竞品B] | | | | |

## 三、功能矩阵对比
| 功能点 | 我方 | 竞品A | 竞品B | 重要性 |
|--------|------|-------|-------|--------|
| [核心功能1] | ✅ | ✅ | ❌ | 高 |
| [核心功能2] | ⚠️部分 | ✅ | ✅ | 中 |

图例：✅ 完整支持 / ⚠️ 部分支持 / ❌ 不支持

## 四、差异化分析
- **我方核心优势**：[2-3 个真实差异点]
- **明显短板**：[诚实列出，不要回避]
- **竞品值得借鉴的点**：[学什么]

## 五、策略建议
- 短期（0-3个月）：[可执行的具体行动]
- 中期（3-12个月）：[差异化深化方向]
- 规避：[不要正面硬碰的方向]
```

3. **数据来源标注**
   - 已知事实打 ✓，推断内容标注 `[推断]`，需验证的标注 `[待核实]`

## Pitfalls

- 不要只列功能有无，要说明实现深度和体验质量
- 差异化优势要真实，不要自我美化
- 如果对竞品不了解，明确告知哪些是推断，不要编造

## Verification

- [ ] 竞品覆盖直接竞品和间接竞品
- [ ] 功能矩阵有明确的重要性权重
- [ ] 差异化分析有具体证据支撑
- [ ] 策略建议可落地，不是套话
