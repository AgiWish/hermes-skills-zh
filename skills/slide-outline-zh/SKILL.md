# PPT 大纲生成 (slide-outline-zh)

## When to Use

- "帮我出个 PPT 大纲"、"这个汇报怎么组织结构"
- 需要快速搭建演示框架
- `/slide-outline-zh [主题 + 目的 + 受众]`

## Quick Reference

```
/slide-outline-zh [主题描述]

可选参数：
  --type=汇报       # 向上汇报 / 述职（默认）
  --type=方案       # 方案提案 / 立项汇报
  --type=复盘       # 项目复盘
  --type=培训       # 知识分享 / 内训
  --pages=10        # 指定页数上限
  --time=20min      # 演讲时间，自动估算页数
```

## Procedure

1. **澄清三要素**（如未提供）
   - 演讲目的：让听众做决策 / 了解信息 / 认可方案？
   - 核心受众：老板 / 客户 / 同事 / 团队？
   - 可用时间：5分钟 / 20分钟 / 1小时？

2. **输出大纲结构**

```markdown
## [主题] 演示大纲

**演讲目的**：[一句话]
**受众**：[角色]
**建议时长**：[X 分钟，共 N 页]

---

### 封面（1页）
- 标题：[主标题]
- 副标题：[补充说明]

### 第一部分：[背景/为什么]（2-3页）
**Page 2** | [页面标题]
- 要点1：
- 要点2：
- 叙事提示：[这页要传达的核心信息]

**Page 3** | [页面标题]
...

### 第二部分：[现状/问题]（2-3页）
...

### 第三部分：[方案/结论]（3-4页）
...

### 结尾（1-2页）
**Page N-1** | 总结 / 下一步
- 核心结论：
- 行动项：

**Page N** | Q&A
---

**叙事逻辑**：[整体故事线说明，如 SCQA / 情境-冲突-解法]
```

## Pitfalls

- 避免每页超过 5 个要点
- 汇报类要先讲结论再讲支撑，不要让听众等到最后才知道答案
- 不要生成太多页数，宁少勿多

## Verification

- [ ] 大纲有清晰的叙事逻辑（不是信息堆砌）
- [ ] 第一页或第二页就能看出核心结论
- [ ] 每页只有一个核心信息
- [ ] 页数和时间匹配（通常 1-2分钟/页）
